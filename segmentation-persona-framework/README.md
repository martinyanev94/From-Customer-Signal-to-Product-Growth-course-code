# Evidence-based Jobs-to-be-Done persona

This small Python artifact models one SignalDesk customer persona and distinguishes structural completeness from evidence gaps.

## Run the example

```bash
python src/personas.py
```

## Run the tests

The tests use only the Python standard library and pytest:

```bash
python -m pytest
```

Evidence references in the example are project-local identifiers. They are placeholders for the insight and interview records maintained by the broader segmentation workflow; unresolved claims remain in `evidence_gaps` until validated.
