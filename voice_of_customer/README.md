# Voice of Customer insight synthesis

This small Python project turns coded customer observations into evidence-linked insight records and a differentiation hypothesis.

## Run

```bash
python3 voice_of_customer/main.py
```

## Test

```bash
python3 -m unittest discover -s voice_of_customer -p 'test_*.py'
```

The sample output is illustrative. A differentiation record remains a hypothesis until the team validates its business implications with follow-up evidence.
