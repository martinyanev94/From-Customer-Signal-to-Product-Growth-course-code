# Stakeholder buy-in operating plan

A small Python standard-library project for validating shared outcomes, decision rights, and cross-functional commitments.

## Run the example

```bash
python3 stakeholder_buy_in_plan/src/main.py
```

Expected output:

```text
Shared outcome: Qualified teams reach a first roadmap decision quickly and understand SignalDesk's value.
Decisions: 3
Commitments: 4
Validation: valid
```

## Run tests

```bash
python3 -m unittest discover -s stakeholder_buy_in_plan/tests -p 'test_*.py'
```
