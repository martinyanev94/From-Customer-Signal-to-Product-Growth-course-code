# Positioning Messaging System

This small Python artifact stores a value proposition and competitive positioning statement as structured fields, then validates that the positioning core is complete.

Run the example from the project directory:

```bash
python -m src.positioning
```

Run the tests:

```bash
python -m unittest discover -s tests
```

The validator checks structure and missing support. It does not prove that a customer claim is true; that requires linked research evidence.
