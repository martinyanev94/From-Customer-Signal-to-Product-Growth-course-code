# Customer-informed roadmap review

This small Python artifact records a roadmap candidate, links it to evidence, and checks consistency with the selected segment.

Run the demonstration from the project directory:

```bash
python -m src.roadmap_review
```

Run the tests:

```bash
python -m unittest discover -s tests
```

The validator checks traceability and structure. It does not prove that customer claims are true; those claims still require review of the underlying market, VoC, and persona evidence.
